# Form Registrasi / Pendaftaran

Project ini merupakan latihan dasar pembuatan **form registrasi (pendaftaran)** menggunakan **HTML dan CSS**.  
Form ini dibuat untuk melatih pemahaman struktur HTML, penggunaan input form, dan styling sederhana.

## Fitur
- Input Nama Lengkap
- Input Email
- Input Password
- Input Konfirmasi Password
- Tombol Submit / Daftar

## Teknologi yang Digunakan
- HTML5
- CSS3

## Tujuan Project
- Melatih penggunaan tag `<form>`
- Memahami berbagai tipe `<input>`
- Membuat tampilan form yang rapi dan user-friendly
- Sebagai latihan dasar sebelum masuk ke JavaScript / Framework

## Cara Menjalankan
1. Download atau clone repository ini
2. Buka file `index.html` menggunakan browser
3. Form siap digunakan

## Catatan
Project ini masih bersifat **statis** dan belum terhubung dengan backend atau database.
